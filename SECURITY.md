# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive information disclosure within this repository, please report it responsibly by opening a confidential security advisory on GitHub or emailing the repository maintainers.

Please provide:
- A description of the vulnerability.
- Steps to reproduce.
- Potential impact.

We will acknowledge receipt within 48 hours and work on a prompt resolution.
